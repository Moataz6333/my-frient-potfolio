How I work

The same path on every project, adjusted to the problem.

  1. Understand

    Interviews, competitor review and the 5 W's to define the real problem.

  2. Structure

    User flows and information architecture so people always know where they are.

  3. Sketch

    Low-fidelity wireframes to test layout and content early and cheaply.

  4. Design

    High-fidelity UI on a consistent design system, responsive from the start.

  5. Test

    Interactive prototypes tested with users, then refined from what they do.
